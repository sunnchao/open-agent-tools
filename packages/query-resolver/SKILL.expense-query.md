# Skill：差旅报销审批查询（口径字典 + 兜底话术）

> 配套代码：`@open-agent-tools/query-resolver`。本文件是 agent 的"业务脑子"：把口语翻译成结构化参数，并处理歧义/缺失/越权。

## 何时用
用户想查"某组织 + 某时间段 + 某费用类型 + 某审批状态"的报销审批数据。典型句式：
"北京分公司上个月的差旅报销审批""上海分 2026年7月 招待费 已通过"。

## 口径字典（先照这个翻译，再调工具）

### 1. 组织（别名 → org_code，按单据生成时快照归属）
| 用户常说 | org_code |
|---|---|
| 北京分公司 / 北分 / 北京分 | BJ-BRANCH |
| 上海分公司 / 上分 / 上海分 | SH-BRANCH |
| 广州分公司 / 广分 / 广州分 | GZ-BRANCH |
> 注意：北京总部(BJ-HQ) 与 北京分公司(BJ-BRANCH) 不同；用户只说"北京"时必须反问确认。

### 2. 时间（相对 → 绝对，统一北京时间 Asia/Shanghai）
- 上个月 / 上月 → 上月自然月 1 号 ~ 月末（默认口径）
- 本月 / 这个月 → 当前自然月
- YYYY年MM月 / YYYY-MM → 该月
- 最近N天 → 含今天往前 N 天
- 本季度 / 上季度 / 去年 → 对应区间
> 用户说了具体时间但解析不出（如"圣诞节那周"）→ 反问，切勿默认上月。

### 3. 费用类型（同义词 → enum）
差旅/出差/差旅费/差旅报销 → TRAVEL（默认）；餐饮/餐费 → MEAL；招待/商务接待 → ENTERTAIN。

### 4. 审批状态
已通过/已审批 → APPROVED（默认）；已驳回/驳回 → REJECTED；审批中/待审批 → PENDING。

## few-shot（原话 → 拆解参数）
1. "北京分公司上个月的差旅报销审批"
   → org=BJ-BRANCH, period=上月, expense=TRAVEL, status=APPROVED
2. "上海分 2026年7月 招待费 已通过"
   → org=SH-BRANCH, period=2026-07, expense=ENTERTAIN, status=APPROVED
3. "北分上月的差旅" → 歧义 → 反问：北京分公司 还是 北分公司(总部)？

## 兜底话术（编排器返回 ok:false 时用）
- `ambiguous`（组织多义）："「<原话>」匹配到多个组织，请确认：① 北京分公司 ② 北分公司(总部)"
- `missing`（缺组织）："没听清要查哪个分公司/部门，例如：北京分公司。"
- `missing`（时间解析不出）："没法理解「<原话>」这个时间段，换个说法吧，比如：上个月 / 2026年7月 / 最近30天。"
- `unauthorized`（越权）："抱歉，暂时没有查询 <组织名> 的权限。"
- `no_intent`（非查询）："没识别到报销查询的意图，可以试着说：北京分公司上月的差旅报销审批。"

## 与工具配合
解析确定后，用 `caliberToArgs(caliber)` 生成 `query_expense_approval` 的入参再调用；
结果连同 `caliber` 一起返回，保证数字可复核、可对账。
